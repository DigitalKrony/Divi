# #MyFriends Sheet

_This is a living project. It will be ever changing and evolving. Beware of these updates._

The **intent** for Divi is to split costs for a group of individuals for any given event. Whether it be dinner, a day long outing with friends, or a planned extended adventure.

### Getting started with terminal development

**Clone the repository with:**

```cmd
git clone https://github.com/DigitalKrony/Divi.git
```

**Once the repository is successfully living on your local machine run:**

_This script will run preinstall and postinstall scripts to initiate your repository for local development_

```cmd
npm run i

or

npm run install
```
